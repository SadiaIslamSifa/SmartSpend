
# SmartSpend — Python Expense Tracker

SmartSpend is a Python project I built to help users track their daily expenses and manage their monthly budgets.

## Features
- Set a monthly budget
- Record multiple purchases and their costs
- Organize expenses into categories such as Food, Shopping, Transport, Grocery, and Rent
- Calculate total spending
- Show the remaining budget
- Warn users when they exceed their budget

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Download `smartspend.py`.
2. Open the file in VS Code.
3. Run `python3 smartspend.py` in the terminal.
4. Follow the instructions to enter your budget and expenses.

## What I Learned
Building SmartSpend helped me practice Python dictionaries, lists, loops, conditional statements, user input, and calculations.
